# Website reference image direction

Verify the real image-generation tool before planning. If unavailable, state the blocker and stop. Do not simulate calls, claim files, or switch into implementation. Generate one horizontal image per requested section (if a landing page has no count, use six only when that default is useful). Never collapse the page into one tall board. Generate a fresh detail image when needed instead of cropping a prior image.

Read the brief before choosing a visual direction. Select a coherent palette, typography mood, image treatment, composition family, and section rhythm. The common left-text/right-image hero is an option, not a default. Use full-bleed or editorial imagery only when it supports the brief; minimal/Swiss requests may stay quiet. Each frame should communicate hierarchy, spacing, CTA priority, component shape, and implementation structure.

Across the set, preserve brand identity, type scale, CTA language, media framing, contrast, and radius logic while varying composition and density by section job. Keep copy short and readable. Avoid generic dark heroes, purple-blue AI gradients, meaningless blobs, fake KPI/dashboard filler, repeated card rows, tiny labels, overpacked layouts, and decorative complexity. Use image content with a clear structural or narrative role and keep text legible over it.

## Optional direction bank

When the brief is open, choose a narrative spine such as archive/specimen, journey/waypoints, precision instrument, living system, or stage/spotlight. Vary anchors deliberately—centered statement, off-grid editorial, bottom-left over image, image-as-canvas with a clear safe zone, stacked center, or an inverted split. A single second-read motif (oversized numeral, side rail, material switch, macro crop, or asymmetric bleed) can aid recall. These options are conditional; do not impose them on a supplied reference or a minimalist brief.

Return labeled generated images (`Section X of N`) and no code. If generation is not available, do not fabricate output.
